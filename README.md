# OpticFiber-SIM
OpticFiber SIM is a complete, educational desktop application. It provides interactive 2D simulations of light propagation, geometric ray tracing, electromagnetic waveguide modes, signal attenuation, dispersion, virtual laboratory experiments, numerical problem solving, and troubleshooting without requiring any internet connection.

Key Features

1.Fundamental Optics

   • Interactive Snell’s Law with real-time ray refraction, normals, angles, and phase velocity.

  • Editable refractive-index material table with custom materials, local storage, and reset options.

  • Total Internal Reflection (TIR) simulator showing refraction, critical angle, and reflection as the incident angle changes.

  • Real-time calculation of: Refractive index,Light velocity,Critical angle,Numerical aperture,Acceptance angle

2.Optical Fiber & Ray Tracing

• Interactive core, cladding, and coating fiber structure.

• Adjustable fiber dimensions and refractive indices.

• Real-time 2D ray tracing showing light propagation and boundary reflections.

• Acceptance cone visualization with acceptance angle and full cone angle.

• Automatic “Why Did the Ray Escape?” diagnostics explaining escape due to:

• Excessive launch angle Incorrect refractive indices Critical-angle violation

3.Advanced Fiber Concepts

• Step-index vs. graded-index fiber comparison.

• Visualization of ray paths and modal dispersion.

• Interactive LP mode simulator with common modes such as LP₀₁, LP₁₁, LP₂₁, LP₀₂, LP₃₁, and LP₁₂.

• Macro-bending and microbending simulations showing radiation leakage and bending effects.

4.Fiber-Optic Communication

• Fiber attenuation and power-budget calculations in dBm and mW.

• Visualization of pulse broadening and dispersion.

• Interactive end-to-end communication link:
              
          Data → Encoder → Source → Fiber → Detector → Amplifier → Decoder

• Automatic link-budget PASS/FAIL analysis.

5.Virtual Laboratory

 Experiment 1 – Numerical Aperture

• Simulate the far-field spot method.

• Adjustable fiber and measurement parameters.

• Observation table with error calculation. CSV export.

Experiment 2 – Critical Angle

• Determine the critical angle experimentally using the grazing condition.

• Record observations and calculate errors. CSV export.

6.Learning & Practice

• Numerical Problem Solver with randomized parameters, formulas, step-by-step solutions, and answer verification.

• Randomized MCQ quizzes with explanations and scoring.

• Troubleshooting Lab with realistic fiber-optic fault scenarios and diagnostic information.

7.Design & Reference Tools

• Build Your Own Fiber with customizable parameters and locally saved presets.

• Formula Board containing important fiber-optic equations.

• Searchable Physics Reference for optical concepts.

• Dark and Light scientific themes for comfortable use.

8.Offline-First

• Runs completely without an internet connection.

• User-created materials, fiber designs, and settings are stored locally.

• Designed as a visual learning tool for students, laboratory demonstrations, and self-study
